# Threshwork web console

Next.js 14 App Router operator UI for the automation portfolio control plane.

```bash
# from repo root
pnpm install
pnpm dev:api    # :4000
pnpm dev:web    # :3000
```

Sign in with API key `ddd_demo_local_dev_key` (sandbox).

See [WEB-APP-SPEC.md](../../WEB-APP-SPEC.md) for IA, screens, and design system.
See root [docs/CODEGEN.md](../../docs/CODEGEN.md) for `pnpm codegen:webapp`.
